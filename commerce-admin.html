Entregas digitales

Configura los archivos que se habilitan después del pago y recupera cobros antiguos de PayPal de forma verificada. Las compras nuevas se bloquean antes del cobro si un producto no tiene entrega configurada.

Archivos por producto

El Worker usa estos datos como fuente de verdad. El enlace que guardes aquí es el que se vincula automáticamente al botón Descargar del cliente en Mi cuenta. Puedes pegar enlaces normales de Google Drive; el backend los normaliza para descarga.

Puedes usar un solo link o varios. Si agregas varios, el cliente verá un botón de descarga para cada archivo. Sin links, las compras nuevas de ese producto quedan bloqueadas antes del cobro.

Recuperar cobro PayPal

Para el cliente que sí fue cobrado pero no recibió archivos. PayPal se verifica en el servidor antes de crear la compra.

El total canónico de esos productos debe coincidir exactamente con lo capturado por PayPal. Si no coincide, el Worker rechaza la recuperación.

Estado del catálogo

Los elementos amarillos están bloqueados para compras nuevas hasta que agregues al menos un archivo.
